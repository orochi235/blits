# teitou (Apple M5 Max, apple metal-3), 2026-11-11, headless Chromium 153.0.8010.12, node v26.13.0, load 3.4-4.3
# The frames where a scene of voices naming 1M subjects starts, in the owned gpu mix of
# 2026-11-10-gpu-owned-groups.txt, after a timing block keeps its state per distinct delay.
# Every run: onto do --kind bench --gui --solo --node teitou.
#
# What changed:
#   - A timing block (src/gpu/timings.ts) finds its voice's distinct delays once (`levelsOf`,
#     src/gpu/levels.ts: a hash on each delay's bits, up to 4,096 levels, else each subject its own),
#     and works out each level's origin, `early` and fade-in origin once. Per subject it keeps only a
#     2-byte code and the f32s the GPU reads; `reorigin` walks levels, not subjects. `Origins` lost
#     its per-delay Map, which cost a lookup per subject. Levels are kept per delays array, so a block
#     remade after a seek or `register` reuses them.
#   - `whole` (src/gpu/answers.ts) hands out the voice's `Named.ordered` rather than an 8 MB copy.
#
# 1. Where main's start frame went, profiled at 35d15d50 (sampled at 100 µs, which roughly doubles a
