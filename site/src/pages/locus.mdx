# Locus

<p class="lede">A locus names voices that are alternatives to one another: one fades out as the other fades in, and halfway through, the subject should look like either of them, not like both at once.</p>

<Locus client:only="react" />

Two voices both write a gain of 0.06, and A hands over to B. Halfway through, each is at weight 0.5.

Without a locus, the mix treats them as two effects stacked on each other. Each is faded halfway toward rest (on `mul`, rest is 1), so each contributes 0.53, and the channel multiplies them: 0.53 × 0.53 reads 0.28. The light brightens in the middle of a handover between two voices that both say "dim". That's the "Without the locus" lamp flaring, and the hump in its curve.

With both voices in one **locus**, the mix treats them as alternatives. It first folds the locus into one influence, blending the members through the channel's own `lerp`, each by its share of the locus's summed weight. That one influence then contributes at weight `min(1, Σw)`, faded toward rest like any other. Both members say 0.06, so the blend says 0.06, and at a summed weight of 1 the subject reads 0.06 the whole way across.

```ts
import { kit, mix, mul, patch } from '@msb235/blits';

const lights = mix<Light, { gain: number }>(kit({ gain: mul() }));
const dim = patch<Light, { gain: number }>(0, () => ({ gain: 0.06 }), { writes: ['gain'] });

const leaving = lights.cue({ patch: dim, locus: 'scene', fade: { out: 2000 } });
lights.cue({ patch: dim, locus: 'scene', fade: { in: 2000 } });
leaving.fade();
```

## Which channels it changes

Switch the channel to `sum` and the two curves lie on top of each other. On `sum`, blending and then scaling is the same arithmetic as scaling and then adding, so a locus changes nothing there. On `mul`, `max` and `last` it's the difference between an alternative and a pile-up: `max` without a locus reads half the gain at the midpoint, and in a locus a `hex` color blends from one alternative to the other instead of switching.

A locus whose weights sum below 1 is faded toward rest by that sum, and one whose weights sum above 1 counts as 1. Every stock channel has a `lerp`, so any of them can be folded this way.

## Blend

`mix.blend(patches, by)` cues several voices into one locus for you, with their weights split by one signal: at 0 the first patch has it all, at 1 the last. Two patches crossfade; more make stops along the way.

```ts
import { level, patch } from '@msb235/blits';

const at = (gain: number) => patch<Light, { gain: number }>(0, () => ({ gain }), { writes: ['gain'] });

const k = level<Light>();
lights.blend([at(1), at(0.3), at(0.06)], k);
k.set(0.5); // halfway between the middle stop and the last
```
